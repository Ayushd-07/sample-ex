## ✨ Project Overview

The **Myntra Dashboard** is a two-page Power BI report created to explore retail sales performance and product-level insights. It brings important business metrics into one interactive report, helping users review orders, revenue, brand performance, category demand, inventory distribution, order status, and city-tier performance.

The report is organized into two main pages:

- 📊 **Sales Overview:** Total orders, revenue, delivered percentage, average order value, city-tier distribution, category-wise orders, and brand-wise orders.
- 🧩 **Product Analysis:** Product distribution, size-wise inventory, brand revenue, top products, order status, and city-tier revenue.

> 💡 **Main Power BI File:** `Myntra_dashboard.pbix`

## 🎛️ Filters & Interactivity

The report includes slicers to explore the data from different perspectives:

- 🏷️ **Brand:** Select one or more brands to focus on their performance.
- 🧺 **Category:** Compare selected product categories.
- 🏙️ **City Tier:** Analyze results across Tier 1, Tier 2, and Tier 3 cities.

Use the page navigation on the left side to switch between **Page 1: Sales Overview** and **Page 2: Product Analysis**. Select chart segments or bars to explore how the other visuals respond to the current filter context.

## ▶️ How to Use

### 💻 Requirements

- Microsoft Power BI Desktop
- `Myntra_dashboard.pbix`

### 🚀 Steps

1. Open `Myntra_dashboard.pbix` in Power BI Desktop.
2. Start on **Sales Overview** to review the main sales and order KPIs.
3. Use Brand, Category, and City Tier slicers to filter the report.
4. Compare orders by category, brand, and city tier.
5. Select **Page 2** to explore product distribution and inventory.
6. Review brand revenue, top products, order status, and city-tier analysis.
7. Clear or change slicer selections to compare different segments.
